# D-043: the fingerprint, one check box for all vaults

Approved by the owner on 22 November 2026 (Proceed).

1. Settings > Security holds one line for it: a check box "Use fingerprint to unlock vault" (on Windows "Use Windows
   Hello to unlock vault"); every other text about it is gone. Without a reader the box is greyed.
2. One setting for all vaults on this computer, no longer per vault (the owner; per vault was the coder's own choice in
   D-038). Ticking asks for one touch, in a popup with Cancel, then the outcome there if something went wrong; the
   key of the vault open then is kept. Every other vault's key is kept at its next master-password unlock, without a
   touch on Linux (Windows Hello asks once). Unticking removes every kept key.
3. The earlier per-vault setting carries over: on for any vault means the box starts ticked.
4. The two Autolock switches showed their knob on "on" while they said "Off" (their word was put beside them by
   mirroring the switch); the word is now a label of its own and the knob shows the truth.
5. The group triangles of the collapsed sidebar are centered in the column, as in the owner's mockup (D-042).
6. Ticking the box first asks the master password of the vault that is open, typed, in the standard password dialog
   (as Set PIN, D-076); never a finger or a PIN (the owner, 27 November 2026: "Otherwise anyone can set a
   fingerprint"). Only when it is proven right does the touch follow; the key kept is the one just proven. Cancel,
   closing the dialog or a wrong password keep nothing and leave the box unticked; a wrong password is said in the
   dialog, which stays open. Unticking asks nothing.
