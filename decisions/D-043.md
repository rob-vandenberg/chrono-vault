# D-043: the fingerprint, one check box for all vaults

Approved by the owner on 22 November 2026 (Proceed).

1. Settings > Security holds one line for it: a check box "Use fingerprint to unlock vault" (on Windows "Use Windows
   Hello to unlock vault"); every other text about it is gone. Without a reader the box is greyed.
2. One setting for all vaults on this computer, no longer per vault (the owner; per vault was the coder's own choice in
   D-038). Ticking asks for one touch, in a popup with Cancel, then the outcome there if something went wrong; the
   key of the vault open then is kept. Every other vault's key is kept at its next master-password unlock, without a
   touch on Linux (Windows Hello asks once). Unticking removes every kept key.
3. The earlier per-vault setting carries over: on for any vault means the box starts ticked.
4. The two Autolock switches showed their knob on "on" while they said "Off" (their word was put beside them by
   mirroring the switch); the word is now a label of its own and the knob shows the truth.
5. The group triangles of the collapsed sidebar are centered in the column, as in the owner's mockup (D-042).
6. Ticking the box first shows the standard dialog that asks the master password (the primary vault's), unchanged,
   whichever vault is open (the owner, 27 November 2026: "Otherwise anyone can set a fingerprint"). Only when it is
   accepted does the second dialog follow, which asks for the finger, as before. A wrong password, the open vault's
   own password or Cancel ask no finger and leave the box unticked; a wrong password is said in the dialog, which
   stays open. Unticking asks nothing. (0.8.125 asked the open vault's own password: wrong, corrected in 0.8.126.)

**Since 0.8.128: the fingerprint for the administrator only (the owner, 27 November 2026).** The administrator is the
person who has the primary vault's password, the master password; a user has only the password of a non-primary vault.
The finger is confirmed by the system against the fingers enrolled there; it stands for the administrator and so reaches
every vault. Therefore:
1. Ticking the box with the primary open asks nothing; with another vault open, or none, it asks the master password
   first, in the password dialog with its own words (D-073). The box no longer needs an open vault.
2. Only the primary vault's key lies behind the finger: never another vault's. Point 2 above (every vault's key kept at
   its next unlock) is replaced; such keys kept by an earlier version are removed at the start.
3. The finger opens only the primary; other vaults open through the primary, as after the master password.
4. Make primary turns the finger off: its key was the old primary's. It is turned on again with the new master password.
5. Point 6 above (0.8.126) stands for the master password; its "unchanged dialog" now carries the action's own words.
