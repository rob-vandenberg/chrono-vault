# D-049: The settings tidied, normal scroll bars, Esc in the About box

Approved by the owner on 22 November 2026 (Proceed, version 0.0.39). Q15 to Q18 were not answered; they were built
as proposed, for the owner to change.

1. Settings > Security, "Autolock when": "Main window is closed" and "System sleeps" are tick boxes, like the other
   two; the four stand in a frame of their own with "Autolock when" as its title.
2. The master password reminder (D-038) is a choice: "Ask for the master password, so it is not forgotten, every"
   Day, Month, Quarter, Year or Never; Quarter by default. It still applies only while a finger unlocks the vault.
3. Settings > Clipboard is one line: "Clear the clipboard after [ 30 ] seconds", the number spinner kept; 0 shows as
   "Never".
4. The settings window and the About box have a normal scroll bar (the owner's picture): an arrow at each end that
   moves a step and keeps moving while held, and a handle that stands out on its track in light and dark. It stands
   in room of its own beside the page, never over the + buttons; that room is kept also when the page fits.
5. The collapsed sidebar's entries are exactly as tall as the expanded ones; their icons are larger (24 pixels at
   100%, scaled with the UI scaling).
6. Esc closes the About box. The cause it did not: the main window's Esc of D-048, while ticked, counted in the
   windows the main window opens too, so two shortcuts claimed Esc there and Qt fired neither. The main window's Esc
   now works only while the main window itself has the keys.
7. The Windows setup is built again: a local name in the keyboard shortcuts' code hid a member of the same name, which
   Microsoft's compiler refuses (no setup since 0.0.35).

**Since 0.6.88 (D-066) Settings has no Customize and no Clipboard: Categories, Tags and Templates are topics of their
own, the rest is under General.**
