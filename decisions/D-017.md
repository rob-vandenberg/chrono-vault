# D-017: Chrono Vault's own look

Approved by the owner on 21 November 2026 (changelist of version 0.0.4).

## What was decided

1. **Chrono Vault sets its own style, Qt's Fusion**, the same on every platform, through one function the program and
   its tests both use, so the tests check what people see. On KDE Plasma the desktop's own Breeze style for Qt Quick
   failed in the editor (`ButtonBackground.qml`, `TextArea.qml`); with Fusion it does not.
2. **The fonts are Google's Noto, carried inside the program**: Noto Sans for all text at 10 points on every system (the
   owner, 23 November 2026, version 0.2.55; 11 in 0.2.54; before, the system's own size), and Noto Sans Mono for
   passwords and one-time codes. They are under the SIL Open Font License 1.1; their licence, `fonts/OFL.txt`, ships in
   every package and beside the program. The owner made an exception to OR-2 for them.
   **One design, identical on every system** (the owner, 23 November 2026): with the same screen scaling and the
   same settings, Chrono Vault looks identical on Linux and Windows; the scalings (its own UI scaling and the
   system's screen scaling) enlarge everything alike, text included. Only what the system itself draws differs: the
   title bars, and Explorer's file dialog on Windows (D-055).
3. **The version stands in every window title**: "Chrono Vault 0.0.4", and "<vault name> – Chrono Vault 0.0.4" with a
   vault open.
