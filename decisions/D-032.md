# D-032: a change made elsewhere

**Taken in autonomous mode** (G-26) on 22 November 2026, within the owner's changelist for `ROADMAP.md` steps 6 to 9
(Q23 taken as recommended). Merging stays `ROADMAP.md` step 10.

## What was decided

1. **Every save gives the vault file a new stamp**: its header and the random nonce of that save, 52 bytes, so another
   computer's save is recognised by reading only the start of the file.
2. **Chrono Vault notices a change made elsewhere** while it runs (the system tells it the file or its folder changed)
   and right before every save of its own.
3. **With no change waiting here, the vault is read again at once** with the key it was opened with, and the list
   shows the new contents; an item open in the editor keeps what the person typed. When the other computer gave the
   vault another master password, the vault locks and says so.
4. **With a change waiting here, nothing is lost**: the person's own version is written beside the vault as
   "<name> (conflict yyyy-MM-dd HH.mm).chronovault", with the same master password, joins the list of vaults, and
   the vault shows the other version; a message names the copy. The person chooses what to keep, until merging comes.
5. **A change kept through a lock** (D-016) is treated the same at the next unlock: when the vault on disk changed
   meanwhile, the kept change goes into a conflict copy instead of over the other version (P6, in part).
6. **A version that cannot be read yet** (a cloud folder still writing it) keeps the vault open and is said; its next
   change is checked again, and until it is read no save goes over it. Only a vault given another master password
   locks.
7. **A vault file is read so that it can be replaced meanwhile** (on Windows a file held open otherwise cannot be),
   and every write of an open vault happens on one thread, after any check of it.

## Replaced in part (D-054, version 0.2.45)

Points 4 and 5 are replaced by merging: a change here and one elsewhere are merged. The conflict copy remains only
for another version that cannot be read with this vault's key.
