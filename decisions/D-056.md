# D-056: Editing categories

Approved by the owner on 23 November 2026 (Proceed, version 0.2.56).

1. **Every category can be edited**, built-in and the person's own: its name, its icon (chosen with the icon picker,
   D-050) and "Shown in the left column", in one Edit dialog. It opens from "Edit…" on each row of Settings >
   Customize > Categories and from a right-click on a category in the left column.
2. **The built-in categories are part of the program** (`src/core/templates.cpp`) with a fixed id, a translated name
   and their own icon. What the person changes of one is kept in the vault under that id (contents format 8,
   `builtInCategories`), so it comes along to every device; Chrono Vault shows it in place of its own. A name left
   as the program has it goes on following the translation; a name the person typed stays the same in every
   language (the owner, Q54). No "Default name" button (the owner, Q56).
3. **The person's own categories** keep their icon in the vault as well (format 8, a category's `icon`).
4. **Reset and Delete** (the owner): beside "Edit…" each row has "Reset" for a built-in category and "Delete" for
   one of the person's own. Reset is always enabled; it puts back the program's name and icon and shows the category
   again; on a category already as the program has it, it changes nothing. Delete works as before (D-027).
5. **Merging** (D-054): the changes to built-in categories and the icons of the person's own are merged like the
   person's own categories: a change on one side is taken, a Reset on one side stands.
6. **Wherever a category is shown** its icon is the one the person gave it, else the program's own: the left column,
   Customize, and an item without an icon of its own.
7. The Edit dialog is made when it is first opened, so the windows hold no hidden dialog before.
