# D-070: The windows and the UI scaling

Approved by the owner on 25 November 2026 (Proceed on the changelist of version 0.6.94).

1. **The main window keeps its size** when the scaling changes; only its contents scale. 960 by 640 times the scaling is
   its size only while it has none of its own.
2. **Every other window and dialog the program creates scales along** with the scaling, from the size the person gave it,
   also one that is closed at the time. Never larger than its screen, never smaller than its minimum.
3. The program's own file dialogs (Linux) too; Explorer's on Windows are not the program's.

`src/ui/window_memory.*` keeps a window's own size as it is at 100%, and with the remembered size the scaling it was left at.
