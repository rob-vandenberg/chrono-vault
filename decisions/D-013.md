# D-013: the encryption

Approved by the owner on 21 November 2026, on the coder's recommendation.

## What was decided

1. **OpenSSL 3, version 3.2 or newer**, is the encryption library, the same library the reference program uses.
2. **The key is derived from the master password with Argon2id**: 64 MB of memory, 3 iterations and 4 lanes for a new
   vault. These numbers are stored in the vault file, so they can be raised later without losing anything.
3. **The vault is sealed with AES-256-GCM**, which keeps the contents secret and also refuses a file of which a single
   byte was changed.

## Why not the reference program's way

The reference program derives its key with PBKDF2-HMAC-SHA512 and encrypts with AES in CBC mode. PBKDF2 costs only
computing time, which graphics cards provide thousands of times in parallel; Argon2id also costs memory for every try,
which takes most of that advantage away. CBC does not notice a changed file by itself; GCM does, which also makes the
"verify before replacing" of every save (OR-15) reliable. This deviation is on purpose, for security (OR-16 point 3).
