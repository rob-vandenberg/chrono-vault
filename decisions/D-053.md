# D-053: The key box as Chrono Viewer's

Approved by the owner on 23 November 2026 (Proceed, version 0.1.44).

Settings > Keyboard shortcuts, after Chrono Viewer's page:
1. The box that waits for a key is a window of its own, "Press the new key", saying "Press a key for “<action>”",
   with a Cancel that never takes the keyboard, so Space, Return and Tab arrive as keys. Only a modifier waits for the
   real key; Esc cancels. A key the action already has changes nothing.
2. While the box waits, or asks about a key in use, no shortcut answers anywhere, Quit and the settings window's OK and
   Cancel keys included: every key is the new key. Cause found with the test: a window's Qt Quick shortcuts still
   answered while a window opened over it held the keyboard, so Shift+Ctrl+P ran Copy Password.
3. A key in use is asked in a window of its own, "Keyboard shortcuts", with a question mark: "This key has already been
   assigned" and "<key> is assigned to “<old>”. Reassign it to “<new>”?", OK and Cancel, Cancel the default. OK
   takes that one key from the old action, which keeps its other keys; Cancel changes nothing.
