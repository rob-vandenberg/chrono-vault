# D-019: the program's icon, the system tray and starting

Approved by the owner on 21 November 2026 (changelist of version 0.0.4).

## What was decided

1. **`art/chrono-vault.svg` is the program's icon**, the owner's own, used everywhere the program shows its icon: the
   windows, the tray, the start and unlock pages (128 by 128, upper left), the Linux menu and the Windows program
   file, Start menu and setup. The build makes the Windows `.ico` and the Linux sizes from it, so it stays the one
   source. Only images the software uses are in git: `art/` is ignored except a line per image in use.
2. **Chrono Vault runs in the system tray**: its icon there shows the window on a click, and its menu has "Show
   Chrono Vault", "Lock" and "Quit". Closing the window keeps it running in the tray, as the reference program does;
   "Quit" and Ctrl+Q end it, asking about unsaved work first (D-016). Auto-lock keeps working while the window is
   hidden. On a desktop without a tray, closing the window ends the program.
3. **The General settings**: "Keep Chrono Vault running in the system tray" (on), "Start Chrono Vault at
   startup" (off; the person's own autostart entry on Linux, their own "Run" entry on Windows, removed again when
   turned off and when Chrono Vault is uninstalled), and "Start Chrono Vault minimized" (off; then every start waits
   in the tray, or starts minimized without one). The vault is never unlocked by any of these.
4. **Logging out or shutting down is never held up**: when the session ends, closing the window ends Chrono Vault
   instead of hiding it in the tray; what is being typed in the editor is stored first, and a running save finishes
   before the program ends (OR-15).
