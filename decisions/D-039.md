# D-039: the menus after the reference program's

Approved by the owner on 22 November 2026 (changelist items 1 to 20, Proceed); the details below taken in autonomous
mode (G-26) are marked so.

## What was decided

1. **File:** New vault, Open vault, Change Master Password, Backup and Restore (greyed until built), Import, Export,
   Preferences, Quit (Ctrl+Q). Lock vault moved to Tools; the theme and UI scaling entries of View are gone.
2. **View:** Show Item Counts, Hide Sidebar, Hide Sensitive (the Security setting itself), then Categories, Tags and
   Others, each showing or hiding its group of the left column. Each choice is kept in the settings.
3. **Item:** Archive (Shift+Backspace), Move to Trash (Backspace), Copy Username (Shift+Ctrl+U), Copy E-mail
   (Shift+Ctrl+E), Copy Password (Shift+Ctrl+P), Show Passwords (Shift+Ctrl+H), Copy URL (Shift+Ctrl+R), Copy OTP
   (Shift+Ctrl+T), Launch URL (Shift+Ctrl+L). A copy takes the chosen item's first field of that kind (a password
   may also be a sensitive text field, as imported), marked secret and cleared after the set time. An entry is greyed
   when the item lacks the field, while the editor is open, and for an item already archived or trashed.
4. **Tools:** Lock vault (Ctrl+L), Clear Clipboard (Ctrl+B, empties it at once), Generate Password (Ctrl+G).
5. **Help:** Check for updates, Support website (the project's GitHub page), About (F1).
6. **Shortcuts** are the reference program's, shown at the right of each entry as written there ("Shift+Ctrl+U"). None
   acts while a text field has the keyboard, so Backspace in the search field deletes a letter.
7. **The one-time code** has a copy button left of its ring.

## Taken in autonomous mode

1. Show Passwords is a plain entry, as in the reference program's picture: chosen once it shows the item's sensitive
   fields, chosen again it hides them; choosing another item or locking hides them too.
2. Launch URL opens an address without a scheme as https; only "scheme://", mailto: and tel: count as a scheme, so
   a host with a port ("nas.local:5000") opens as https too.
3. Once the vault page shows, the keyboard goes to the item list. Before, it stayed in the hidden password field of
   the page left behind, so typed letters went there and no shortcut could act.
4. The five menus use the style's own entry (Fusion's menu builds its own otherwise) and are as wide as their widest
   entry.
5. Ctrl+Q keeps working in the program's other windows, as before.
6. A group of the left column hidden while one of its entries is chosen: the list goes back to Home.

## Changed in 0.2.47 (the owner, 23 November 2026)

Show Item Counts shows only counts above 0. A sidebar name too long for its room ends in "…" before its count, and
takes the count's room when none is shown.

## Changed in 0.2.50 (the owner, 23 November 2026)

While a text field has the keyboard, a shortcut stands aside only when its key edits text: plain keys and Shift plus a
key; Backspace, Delete, Enter, Tab, the arrows, Home, End, Page Up and Page Down (alone or with Shift); Ctrl+A, C, V,
X, Z, Y, Shift+Ctrl+Z, Shift+Insert, Ctrl+Insert, and Ctrl or Shift+Ctrl with Backspace, Delete, the arrows, Home or
End. Every other key is a command while typing: F1 on the unlock page, Ctrl+L, Shift+Ctrl+P and so on.

**Since 0.5.82 (D-062) Backspace and Del ask first.**
