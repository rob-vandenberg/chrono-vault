# D-048: Use the Esc key to exit the program

Approved by the owner on 22 November 2026 (Proceed, version 0.0.38).

1. Settings > General: the check box "Use the Esc key to exit the program" (the owner's words, after Chrono Viewer),
   below "Keep Chrono Vault running in the system tray"; off by default; kept with OK, put back by Cancel and by
   Restore defaults like the other boxes there.
2. Ticked, Esc in the main window works as the window's close button: to the system tray when Chrono Vault keeps
   running there, otherwise the program ends, after the usual questions about unsaved work.
3. Esc works only in the main window and not in edit mode (the owner). Held down it does not repeat; with Shift, Ctrl
   or Alt it does nothing; an open menu or dialog takes its own Esc first.

**Since 0.5.82 (D-062) Esc cancels the editor.**
