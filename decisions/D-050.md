# D-050: The icon picker

Approved by the owner on 22 November 2026 (Proceed, version 0.0.40).

1. The item editor's top row: "Add ▾" at the left; Save, then Cancel, at the right; 12 pixels between the buttons
   and the icon below. A click anywhere on the item's icon opens the icon picker; the old menu ("Choose icon…",
   "Remove icon") is gone.
2. "Choose Icon", after the reference program's picker, with a Search field at the top since 0.2.57 (see point 9):
   "Custom Icons" first, starting with "Default icon" (the item's category's icon), then one section per folder named in
   `icons.md`. The chosen icon carries a blue circle with a check mark; OK is greyed until an icon is chosen; Cancel;
   "Add Custom Icon" at the bottom left adds a picture (JPG, PNG, BMP, ICO, SVG) to the vault's own icons and chooses
   it; a right-click on one of the vault's own offers "Delete icon", asked first when items carry it, which then get
   their category's icon.
3. The vault's own icons are kept inside the vault (contents format 5), so the same vault shows them on every device
   (the owner). An item keeps its icon as its own PNG, also when it came from a shipped icon.
4. The icons that ship: the project's `icons/` folder, `icons.md` with one line per section ("folder: Heading", in
   the order shown; empty lines and lines without a colon skipped; other folders ignored) and the folders `web`,
   `creditcard`, `miscellaneous`. It is installed beside the program (`/opt/chrono-vault/icons`,
   `C:\Program Files\chrono-vault\icons`) and copied at each start into the person's own folder
   (`~/.local/share/chrono-vault/icons`, `%LOCALAPPDATA%\chrono-vault\icons`, Local and not Roaming as Microsoft
   advises for larger files); nothing already there is written over, so a person's changes stay. The picker reads the
   person's folder.
5. The headings go through the translation (context "IconSections"): `update_translations` takes them from
   `icons/icons.md`; a heading without a translation is shown as written.
6. Settings > Security: the master password reminder stands just below "Change the Master Password".
7. **Folders inside folders and lines taken out** (the owner, 23 November 2026, version 0.2.56): a line of
   `icons.md` may name a folder inside a folder (`symbols/uppercase: Uppercase`); each such folder is a group of its
   own, the groups a flat list in the order of `icons.md`, never by name. A path outside the icons folder (`..`, `.`,
   from the root, a backslash) is refused. A line starting with "-" marks a folder the person took out: never shown,
   never touched, never added again. At each start a folder that ships and that no line of the person's `icons.md`
   names, shown or taken out, is added at its end, so new icons appear after an update; their own lines stay.
8. **An icon's name is its file name** (the owner, Q48): shown as its tooltip in the picker, and gathered by
   `update_translations` into the translation file (context "IconNames"), so it can be translated with Poedit.
   Shipped now: `icons/categories` (30, single lowercase words) and `icons/symbols/uppercase`, `lowercase` and
   `digits` (62, named by their character; folders, because Windows does not tell `A.svg` from `a.svg`).
9. **Searching the icons** (the owner, 23 November 2026, version 0.2.57): a "Search" field at the top of Choose Icon,
   as the one above the item list. It narrows the icons by their shown name, any case, anywhere in the name ("boba"
   finds RABOBANK); a group without a match is left out, and so are the vault's own icons, which have no names. The
   field is empty each time the picker opens.

**Since 0.6.91 (D-068) Choose Icon opens in Search and works by keyboard.**
