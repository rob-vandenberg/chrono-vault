# D-051: Arrow keys, the one Notes, every field type, our own switch

Approved by the owner on 23 November 2026 (Proceed, version 0.1.41).

1. In the item list, Up, Down, Page Up, Page Down, Home and End show the item they move to in the right column, as a
   click does; an edit not saved yet is asked about first.
2. The item view's cards stand on the theme's Base colour (`#1f2124` dark, white light), the owner's picture.
3. Every item has exactly one Notes: the item's own note, always shown in the editor below the fields and above
   Tags ("Notes", placeholder "Add Note"), never deleted. The built-in templates no longer add a "Notes" field. A field
   a person names "Notes" is an ordinary field like any other (the owner).
4. The field types are the reference program's twenty, with its names and in its order: Text, Password, PIN,
   Numeric, Date, Email, URL, Phone, Username, One-time Code, Multiline, Cardholder Name, Card Number, CVC, Card PIN,
   Expiry Date, Bank Name, Transaction Password, Card Type, Valid From. The six new ones are stored under its words
   (`pin`, `ccName`, `ccNumber`, `ccBankname`, `ccTxnpassword`, `ccValidfrom`; found as texts in its program file,
   nothing of its code read), so an import and an export keep them; contents format 6. A new PIN and Transaction
   Password field is sensitive. The template editor keeps its five types (D-027).
5. Chrono Vault's own switch (`style/Switch.qml`), after the owner's approved mockup: a rounded track with a round
   white knob; off grey with the knob at the left, on the theme's blue with the knob at the right; used wherever the
   program shows a switch.
