# D-081: Sort By, and the letter keys in the item list

Approved by the owner on 27 November 2026 (Proceed on the changelist of version 0.8.119; Q13, Q14, Q16 and Q17 of
that brainstorm).

1. **Sort By** above the item list: Title, URL, Created Time, Modified Time, Recently Used, Frequently Used; a line;
   Ascending, Descending. One tick in each part. The button shows the order by its name.
2. **Ascending** is A to Z, oldest first, least used first; **Descending** the other way. Two items alike stand by
   title, A to Z. Items never used stand first going up (least used), last going down. A new vault starts on Title,
   Ascending.
3. **Group headings only by Title** (Q14, the reference program's way); every other order is one plain list. The
   groups of the "reused" audit keep their headings in any order (D-065).
4. **A use** is a field of the item copied (a double click, the Copy entries, the code's copy button, the Item
   menu, a value from a field's history) or its website opened (the Item menu's entry, a web address's link).
   Auto-type counts too once it exists; the program has none yet. Each item's last use and its count are kept on this
   computer only, never in the vault (Q13): in the vaults file, a group per vault named after its place
   (`src/ui/item_order.*`).
5. **Sort By and its direction are kept per vault**, on this computer (Q17), in the same file.
6. **A key in the list** (Sort By on Title, the keyboard in the list, not in Search): the first key typed brings that
   letter's heading to the top of the list; "0" to "9" go to "#"; a letter without a heading goes to the next heading
   after it in the list's direction, or to the end (Q16). Near the end the list goes only to its bottom, never to empty
   room below. The keys still choose the item that starts with what is typed, as before (D-062).
7. **The list's end is laid out first** (`itemList.headingToTop`): the list knows where its bottom is only once the
   rows there are laid out; before that it held a heading near the end short of the bottom, the last row cut off.

Tests: `test_intuitive_sorting` (every order and direction, headings only by title, a use counted for a copy and the
website opened, kept per vault, the letter cases).
