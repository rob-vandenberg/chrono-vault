# D-036: website icons

**Taken in autonomous mode** (G-26) on 22 November 2026, within the owner's changelist (points 23 and 37); the owner:
"as the reference program does, but only when that option is active"; Q36 taken as recommended.

## What was decided

1. **Settings > Customize > "Use website icons"**, off by default, kept per computer, as in the reference program.
2. **Each website itself is asked for its icon** (`https://<site>/favicon.ico`), never a service in between, so no
   one learns the list of sites in a vault; each website only learns that its icon was asked for. The window says so
   under the setting.
3. **An item's website** is the site an import named, else its first web address. Each website is asked once per
   unlock, however many items share it; not for an item in the Trash. An item with an icon of its own keeps that
   icon. An icon larger than 512 KB is broken off while it downloads.
4. **The icons are kept in memory only, never on the disk**, because a cache file would name the vault's sites in
   plain text (`REQUIREMENTS.md` 4.1); they are forgotten at every lock and asked for again after the unlock.
5. **A website without an icon**, or one that cannot be reached, leaves the category's icon; nothing is said.
   Turning the setting off shows every item's own or category's icon again at once.

**Since 0.6.88 (D-066) Settings has no Customize and no Clipboard: Categories, Tags and Templates are topics of their
own, the rest is under General.**
