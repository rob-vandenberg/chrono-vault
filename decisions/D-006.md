# D-006: what the first version leaves out

Approved by the owner on 20 November 2026, before any code existed.

## What was decided

The first version has none of these:

1. **Browser integration**: no browser extension and no filling of web pages.
2. **Autofill on phones** (D-007).
3. **Sharing** items or vaults with other people. Sharing would need a server we run, and sharing a login with its
   password hidden cannot work without autofill.
4. **Syncing over Wi-Fi** between devices.

## Why

Together they would have added many months of work; storage in a folder or cloud folder (D-005) already keeps the
person's devices the same.
