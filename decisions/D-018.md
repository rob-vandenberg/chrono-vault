# D-018: item icons

Approved by the owner on 21 November 2026 (changelist of version 0.0.4).

## What was decided

1. **Every item can have an icon of its own**, picked by the person: JPG, PNG, BMP, ICO or SVG. It shows in the editor
   (64 by 64) and in the list (32 by 32).
2. **The icon is stored inside the vault, encrypted**, so it syncs with the vault and tells nothing about the person's
   sites. It is scaled to fit 64 by 64, never stretched, and kept as PNG; the picked file itself is not kept.
3. **Files over 5 MB, damaged files and other formats are refused**, each with its own message (OR-4).
4. **An item without an icon shows its template's own**: a key for a login, a sheet for a note, drawn for Chrono Vault.
5. **No website icons are fetched**: that would send the person's list of sites over the network.
6. **The contents format is 2**: format 1 is still read; Chrono Vault 0.0.3 refuses a vault of format 2 instead of
   saving it back without its icons (D-015, OR-15).
