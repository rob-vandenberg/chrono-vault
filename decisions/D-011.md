# D-011: one settings window

Approved by the owner on 21 November 2026, before any code existed.

## What was decided

**Chrono Vault has one settings window that holds every setting**, in the style of all the owner's programs: a
sidebar on the left to pick the topic, and a content pane on the right where the settings of that topic are changed.
Chrono Viewer's settings window is the example.

**This differs from the reference program on purpose**, so OR-16 does not apply to the layout of the settings window.

## Open

How the window looks on a phone screen, which is too narrow for a sidebar and a content pane side by side, is decided
when the phones are reached (`ROADMAP.md` step 17).
