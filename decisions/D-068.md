# D-068: The keyboard in dialogs; the text fields' menu

Approved by the owner on 25 November 2026 (Proceed on the changelist of version 0.6.91).

1. **A dialog with a text field to type in opens with the keyboard in it.** Elsewhere, by purpose: the WebDAV window (the
   choice of server), the WebDAV file dialog when opening (the list), Generate Password (its field shows the result),
   Import (its first choice) and Settings (the topics).
2. **Tab moves from field to field, in the dialog's order**; no other key does.
3. **Choose Icon**: Search, then the icons with an outline around one, then the buttons. The arrows move the outline, over
   the headings, Page Up and Page Down a page, Home and End to the first and last. Enter takes the outlined icon and
   closes, Esc cancels. The mouse as before: the blue check is what OK takes.
4. **Every text field has a right-click menu**: Cut, Copy, Paste, Select All, grey when it cannot be done; what a password
   field hides is never cut or copied. Qt 6.9 or newer.

**Since 0.6.93** also the unlock page when the program starts on a locked vault.
