# D-052: Esc as Chrono Viewer has it

Approved by the owner on 23 November 2026 (Proceed, version 0.1.42).

On one of the owner's laptops (Kubuntu, X11) Esc no longer closed the About box with "Use the Esc key to exit the program"
ticked, also after clicking inside it. Chrono Viewer had the same fault days before and fixed it twice over; both
fixes are taken over:
1. Chrono Viewer `786104c`: Esc is not a shortcut. The main window's Esc (D-048) is taken by the window's own keys
   (`Keys` on its content), so it arrives only when nothing in the window took it first, and never competes with a
   dialog's own Esc. The 0.0.39 patch (the shortcut only while the main window holds the keyboard) is gone.
2. Chrono Viewer `ae07b6c`: the keyboard stays in the window's content. When a menu closes, or nothing has the
   focus, it goes back to the item list, or to the master password on the unlock page, so the menu bar never keeps Esc.
3. Version 0.1.43: every dialog (`qml/DialogWindow.qml`) also takes Esc in its own keys, as Chrono Viewer's `QDialog`
   does, so Esc closes the About box also where its Cancel shortcut does not fire.
