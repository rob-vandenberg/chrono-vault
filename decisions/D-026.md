# D-026: --reset, and the two files

Approved by the owner on 22 November 2026 (changelist of version 0.0.12); rewritten at his order for version 0.0.38
(Proceed of 22 November 2026).

## What was decided

1. Chrono Vault keeps what it stores in two files, side by side in its folder: `~/.config/chrono-vault/` on Linux,
   `%APPDATA%\chrono-vault\` on Windows. The registry is not used for them (the system's startup entry is not ours).
   1. `chrono-vault.conf`: the vaults as they are configured: the list of vaults and the last one, each vault's
      keyfile place, which vaults have a fingerprint key kept (with the Windows Hello data), when each vault's master
      password was last typed, and the login tries with their waits (D-041), so a reset never skips a wait.
   2. `chrono-vault.ini`: everything else: every setting the settings window can change (keyboard shortcuts and "Use
      fingerprint to unlock vault" included), and what is stored on the fly: window sizes, places and states, the
      View menu's choices, the updater's answers.
2. `chrono-vault --reset` deletes `chrono-vault.ini` at the start, before anything reads it. Deleting that file by
   hand has exactly the same effect: the program as it is after a fresh install and adding a vault.
3. No backwards compatibility (the owner: "we start from scratch"): nothing from earlier versions is carried over.
