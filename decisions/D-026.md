# D-026: --reset

Approved by the owner on 22 November 2026 (changelist of version 0.0.12).

## What was decided

`chrono-vault --reset`: at the start, the places that read the settings window's settings from the settings file are
skipped, so those settings start at their defaults: the lock time, the clipboard time, keep running in the tray,
start minimized, check for updates, the theme and the UI scaling. Nothing is written, nothing is removed, nothing
else changes. "Start at startup" is read from the system's own startup entry, not from the settings file.
