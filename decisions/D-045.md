# D-045: Keyboard shortcuts set by the person

Approved by the owner on 22 November 2026 (Proceed).

1. Settings > Keyboard shortcuts, after Chrono Viewer's page: every action of the menus plus "Collapse or expand the sidebar" on its row with the menus' own words; its keys one under the other, a cross after each, a [ + ] on the first line; a key is pressed, not typed; Escape stands greyed on the first line and cancels the box.
2. A key already taken asks "This key has already been assigned": OK moves that one key, Cancel changes nothing. An action may have no key.
3. The keys are kept in the settings; each menu entry shows the first key as it is now; OK keeps, Cancel throws away, Restore defaults puts back the starting keys.
4. Ctrl+B collapses or expands the sidebar; Clear Clipboard moves to Shift+Ctrl+B (the owner).
5. Help > Keyboard shortcuts... opens the page.
6. Shortcuts still stand aside while a text field is typed in (D-039); Quit answers in every window.
